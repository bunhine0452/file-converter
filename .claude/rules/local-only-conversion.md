# 로컬 변환 원칙 (프로젝트 존재 이유)

이 앱이 설치형인 이유는 **파일이 기기를 떠나지 않는 것**이다. 위반 시 제품 전제가 무너진다.

- 사용자 파일의 내용(일부 바이트 포함)을 네트워크로 전송하는 코드를 절대 작성하지 않는다. 클라우드 변환 API·원격 OCR·텔레메트리에 파일명/내용 포함 모두 금지.
- 허용되는 네트워크 사용은 두 가지뿐: (1) 도구 바이너리 온디맨드 다운로드(LibreOffice 등, 해시 검증 필수), (2) 앱 자동 업데이트.
- 변환은 전부 로컬 프로세스(Rust 코어·사이드카·soffice headless)에서 수행하고, 임시 파일은 변환 종료 시 삭제한다.
